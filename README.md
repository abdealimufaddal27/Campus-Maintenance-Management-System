# 🏫 Campus Maintenance Management System

A simple campus maintenance management system built to make it easier to **report, track, update, and analyze maintenance complaints**.

The project helps keep all complaints and maintenance records organized in one place, while also providing a dashboard for viewing complaint status, repair costs, and basic reports.

## ✨ Features

- 📝 Add and manage complaints
- 🔎 Search complaints easily
- 🔄 Update complaint status
- 🛠️ Add technician and maintenance details
- 💰 Track repair costs
- 📊 Dashboard with basic statistics and charts
- 📁 Export complaint data as CSV

## 🛠️ Built With

- **Python**
- **SQLite**
- **Tkinter**
- **Streamlit**
- **Pandas**
- **Matplotlib**
